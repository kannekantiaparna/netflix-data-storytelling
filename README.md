# 📖 Netflix Data Storytelling App

A data storytelling application that walks through Netflix's
content library with meaningful insights and visualizations.

## 📊 Story Chapters
1. Netflix's Content Growth Journey
2. Movies vs TV Shows Battle
3. Global Content Map
4. Genre Landscape
5. Netflix's Content Calendar

## 🛠️ Tech Stack
Python | Pandas | Plotly | Google Colab

## 📁 Dataset
[Netflix Movies and TV Shows – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## ▶️ How to Run
Open `netflix_storytelling.ipynb` in Google Colab and run all cells.
